\section{What the atlas contains}
\label{sec:design}

The release comprises \AtlasTotalFamilies{} experiment families organised into
\AtlasTotalBlocks{} blocks, \AtlasTotalConditions{} registered conditions, and
\AtlasTotalRuns{} trained models. Figure~\ref{fig:atlas-taxonomy} places every
family on two axes: the block it belongs to, and how much analytic support the
setting already has.

\subsection{Design rules common to every family}

\paragraph{The control grid must be able to hold a boundary.}
Every family sweeps its primary control on a grid of at least twelve points,
logarithmic where the control spans decades. This is not a cosmetic choice. An
interior maximum cannot be distinguished from an endpoint on a three-point
grid, and a Binder crossing cannot be interpolated from one; a coarse grid does
not produce a weak result, it produces a structurally negative one. The single
largest methodological difference between this release and its predecessor is
the density of the control axis.

\paragraph{The scale path must be a path.}
Each family declares a scale coordinate --- width, dimension, depth, training
set size, generation count --- and samples at least three, usually five or six,
values of it. ``A larger model'' is not a scale path; the coordinate has to be
named, because the finite-size fits of \eqref{eq:sharpening} and
\eqref{eq:drift} are statements about a specific one.

\paragraph{The disorder ensemble must be outer.}
Every condition is run under \AtlasSpecializationSeeds{} independent outer
seeds, each fixing both the initialisation and the data draw. This is what
gives $\chi_N$ and $U_4$ in \eqref{eq:chi-binder} their meaning, and it is why
no family here reports a fluctuation computed along a single trajectory.

\paragraph{Optimisation quality must be equalised, not the epoch count.}
Runs are trained to a common relative-improvement criterion with a generous
cap, and each run records the epochs it used and whether the criterion was
met. Under a fixed epoch budget a wider model is optimised less thoroughly than
a narrow one, so an apparent size dependence of an order parameter can be
optimisation shortfall wearing the costume of physics. We encountered exactly
this: at a fixed budget the specialisation order parameter appeared to
\emph{decrease} with width, reversing sign once the budget was replaced by a
convergence criterion.

\subsection{Reproducibility}

Every run is content-addressed by its condition and seed, so an interrupted
sweep is resumed rather than repeated and no result is silently recomputed
under different code. All paths are supplied through environment variables, so
the same code runs unchanged on a laptop, a scheduler, or a cloud runtime. The
numbers quoted in this paper are generated as \LaTeX{} macros directly from the
strict aggregate: a value in the prose that has no run behind it does not
exist, which is a stronger guarantee than a careful author.
