\section{Experiment grammar and predictive phase continuation}
\label{sec:method}

Every run is generated from four typed objects. A \emph{ScientificSpec} names
the question, state object, deformation, phenomenon, theory status, fidelity,
and observables. A \emph{ProtocolSpec} fixes controls, outer and inner disorder,
finite-size path, nulls, interventions, calibration, and holdouts. An
\emph{ExecutionSpec} fixes implementation, resources, seed streams, and
software identity without changing scientific identity. An
\emph{EvidenceVector} records semantic validity, replication, finite-size
diagnostics, prospective prediction, intervention, and external validity.

The output of an estimator is not a bare float but
\begin{equation}
\widehat O=(\bar O,[O_-,O_+],q,U,n_{\rm outer},n_{\rm inner},
\mathcal S_{\rm outer},\text{units}),
\end{equation}
where $q$ is interval level and $U$ names the uncertainty method. The ensemble
is part of the observable: checkpoint-to-checkpoint variability is a temporal
statistic, whereas susceptibility and Binder cumulants used here are computed
over independent terminal outer-seed samples.

\subsection{Predictive phase continuation as one atlas protocol}

Let $\mathcal O_{\rm cal}$ be registered calibration observables and
$\mathcal O_{\rm solv}(\bm\theta)$ a solvable surrogate. We estimate
\begin{equation}
\widehat{\bm\theta}_{\rm eff}
=\arg\min_{\bm\theta}
D\!\left(\mathcal O_{\rm cal}^{\rm target},
\mathcal O_{\rm solv}(\bm\theta)\right),
\end{equation}
then predict an order curve, a boundary $\gchat$, transition diagnostics, and
an intervention response. The bridge error is evaluated only on withheld
quantities,
\begin{equation}
\Ebridge=
D\!\left(\mathcal O_{\rm holdout}^{\rm target},
\mathcal O_{\rm solv}(\widehat{\bm\theta}_{\rm eff})\right).
\end{equation}
Semantic retention $S_{\rm sem}=I(m;Z)/H(Z)$ is a separate estimand: a small
boundary error is meaningless if $m$ no longer tracks the latent variable
$Z$.

\paragraph{Baselines.}
Every predictive comparison includes a constant predictor, direct transport of
the source boundary, a size-only or nearest-calibration predictor, the base
surrogate, and the registered augmented surrogate. A diagonal plot without
these controls cannot distinguish physical transport from simulator
reparameterization.

\paragraph{Breakdown and repair.}
Two assumptions can interact through
\begin{equation}
\Delta_{ij}\gc=\gc^{ij}-\gc^i-\gc^j+\gc^0.
\end{equation}
Holdout A is used only to diagnose a missing coordinate. Candidate
macrovariables and their selection rule are frozen on a calibration split.
Only Holdout B can support a repair claim. When an augmented surrogate was
specified before either holdout, we call it a preregistered comparison, not a
post-hoc repair.

\paragraph{Prediction target.}
A threshold estimate is recorded as crossed, left-censored, or right-censored.
Only crossed estimates enter boundary-error summaries. Censored curves remain
visible because the absence of a crossing is often the scientific result.

\paragraph{Attempt and invalidation semantics.}
A failed accelerator attempt and a CPU fallback are separate attempts under one
scientific condition. Artifact identity records scientific, protocol,
implementation, and execution hashes separately. If a metric definition,
ensemble, split, or selection rule changes, the prior artifact is retained but
marked invalidated for the affected claim; it is never silently reinterpreted.
