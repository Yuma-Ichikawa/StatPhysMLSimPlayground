# Where Theory Ends — numerical statistical-mechanics atlas

`main.tex` is the only manuscript entry point. Its sections, references,
generated result macros, figure suite, and compiled PDF are colocated here. The
repository intentionally contains no second paper tree.

`main.pdf` is built from the current sources. Rebuild it after regenerating
macros or figures; see **Build** below.

## Where the numbers come from

Every measured value in the prose is a `\newcommand` in `generated/atlas.tex`,
emitted directly from the strict aggregate of the experiment program. A number
typed into the text by hand would not survive review, and a macro with no run
behind it does not exist. Regenerate with:

```bash
source <atlas>/env.sh
python -m sma.macros --output <repo>/paper/generated/atlas.tex
```

The experiment program itself lives outside this repository, in the work area
described by `<atlas>/README.md`. It is parameterised entirely by environment
variables, so it can be pointed at this `paper/` directory from any machine.

## Figures

`figures/atlas_taxonomy.pdf` and `figures/atlas_map.pdf` are the atlas-level
views; `figures/family_*.pdf` is one four-panel finite-size dossier per
experiment family (order parameter, disorder susceptibility, Binder cumulant,
attempted scaling collapse). All are generated by:

```bash
python -m sma.figures
```

Encoding conventions are fixed across every figure. System size is an ordered
magnitude and is drawn with a single-hue sequential ramp whose perceptual
lightness is asserted monotonic in code; block identity uses a fixed
categorical order validated for colour-vision-deficiency separation; verdicts
use a reserved status palette and are *always* written as text, so colour is
never load-bearing.

Figures from the previous manuscript (`figure1_*` … `figure20_*`) remain in
this directory but are no longer referenced by `main.tex`.

## Checking the manuscript without compiling it

`sma.checktex` performs the checks a compiler would catch — unresolved
`\input`, a generated macro used but never defined, a missing figure, a
`\ref` to an undeclared label — and needs no TeX toolchain:

```bash
python -m sma.checktex --paper <repo>/paper
```

## Build

With a full TeX installation:

```bash
cd paper
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Or, with no TeX installation at all, using a self-contained engine that fetches
only the packages this document needs (`brew install tectonic`):

```bash
cd paper
tectonic -X compile main.tex
```

The current release builds clean under tectonic 0.17: 30 pages, no undefined
references, one 0.8 pt overfull box.

Deployment-owned paths, accounts, partitions, node names, and scheduler policy
remain runtime inputs and are never embedded in the manuscript or figures.
