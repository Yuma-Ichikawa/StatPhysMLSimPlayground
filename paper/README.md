# Numerical statistical-mechanics atlas paper

`main.tex` is the only manuscript entry point. Its sections, references,
generated result macros, figure suite, and compiled PDF are colocated here. The
repository intentionally contains no second paper tree.

## Figure contract

The nine manuscript figures are generated by one script with one palette, font
hierarchy, marker order, and panel-label convention. Every PDF and PNG has the
exact physical size `6.4 x 4.8` inches; PNG output is 300 dpi. The generator does
not use tight bounding boxes, so the physical dimensions do not drift.

```bash
python scripts/generate_paper_figures.py \
  --reference evidence/tensor_reference_validation/aggregate.json \
  --confirmation-macros paper/generated/phase_tensor_confirmation_results.tex \
  --output paper/figures \
  --macros paper/generated/reference_results.tex
```

Conceptual figures encode the taxonomy, evidence ladder, observable map, and
decision rule. Quantitative figures are derived only from committed strict
aggregates and generated macros. The public GPU reference has five independent
full-pipeline seeds per condition; missing or failed registered seeds invalidate
strict aggregation.

## Build

```bash
cd paper
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

For a full scheduled-data refresh, use `scripts/phase_tensor/render-paper.sh`.
Deployment-owned paths, accounts, partitions, node names, and scheduler policy
remain runtime inputs and are never embedded in the manuscript or figures.

Before release, tests verify figure dimensions, manuscript-to-manifest coverage,
the 360-task dense-confirmation design, and the absence of machine-local paths.
