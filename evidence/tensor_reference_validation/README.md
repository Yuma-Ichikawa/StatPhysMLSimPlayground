# Tensor outer-seed reference validation

This portable evidence bundle was generated by the registered configuration in
`experiments/phase_continuation/configs/tensor_reference_validation.toml` using
one accelerator through Slurm. It contains 45 completed full-pipeline runs:
three controls, three declared finite widths, and five independent outer seeds.

- `aggregate.json` contains canonical estimates, intervals, raw outer-seed
  values, runner contracts, scale metadata, and the evidence vector.
- `summary.csv` is a flat table for independent inspection.
- `report.html` is a self-contained visual report with no external or local
  URLs.

This is a short pipeline validation, not a confirmatory transition study. Its
evidence vector is grade C: replication and observable registration are present,
but semantic nulls, prospective largest-size prediction, matched intervention,
and external validity are absent. The observed response curves therefore support
only the wording “response shift”; they do not support a universality or phase
transition claim.
